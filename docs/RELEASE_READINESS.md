# SAGE 发布就绪清单（2026-09-30）

> 本文件下方的 2026-09-23 证据表是历史快照。2026-09-30 最新本地验收：后端隔离测试 116 项通过；前端生产构建和 TypeScript 通过；内置浏览器验证普通成员与管理员主要路径，并完成一条纠错提交、采纳、成员可见闭环。隔离临时库的 DeepSeek Flash 真实测评生成 9 道题、5 项学习任务，但学习计划复审仍标记 `needs_review`；未经专业复核的计划不能当作已验证的操作手册。发布到 GitHub 是源码发布，不等于生产部署或专业质量认证。

## 当前结论

- **本地可试用**：登录、两种 Glue 故障排查场景、证据查看/提交/历史回访、已有学习计划的完成证据与历史报告。
- **真实 AI 流程已在本机跑通**：模型列表返回 `deepseek-flash` 和 `deepseek-v4-pro`，两者均完成 9 题出题。使用 `deepseek-flash` 完成一轮前测、9 题评分、11 条盲区诊断、学习计划、后测和历史报告复开；后测结果包含前测雷达用于对比。仅一次样本，不代表题目专业准确性或评分一致性已验收。
- **不应称为生产就绪**：远端 CI 未推送运行，题目与评分质量缺少多样本人工评审，任务执行仍为进程内线程；服务重启会中断正在执行的任务并标为失败。SQLite 适合本地/小规模试点，正式多实例部署还需要数据库迁移与任务队列。
- **Glue 质量修正**：已建立 12 道 AWS 官方文档可追溯题库，并将 Glue 默认生成素材收敛到公开考点；既有两套 18 道题初审发现内部实现/标准答案风险，详见 [Glue 质量评测](GLUE_QUALITY_EVAL.md)。旧会话仍保留原题，不能视为专业验收通过。
- **自研工作流加固**：所选模型随题目会话进入评分、诊断、规划和反思；计划经确定性约束与 LLM 反思检查，必要时最多修订一次，并持久化最终审核状态。Glue 题目需要引用策展来源 ID；来源绑定不证明语义正确。

## 下一轮验收与上线条件

1. 模型配置和 `/models` 发现已经在本机验证；选题页面可刷新并切换模型。密钥只保存在 `backend/.env`，不要提交到 Git 或贴进聊天。
2. 开发环境管理员的 `/api/llm/ping` 探针已成功返回模型内容。
3. 一次真实前后测功能闭环已完成；Glue 的 12 道事实题和一个固定评分场景已有双模型实测，但仍须由熟悉 AWS Glue 的人员评审生成题、标准答案、开放题评分和学习建议，并跨模型、跨服务重复抽样。其余自动化验收使用模拟模型响应，不能代表专业质量。
4. 若部署到公网：配置 HTTPS 反向代理、至少 32 字符的随机 `AUTH_SECRET`、真实站点 `CORS_ORIGINS`，并在生产环境交互式创建管理员。升级 SQLite 前先运行备份命令。

## 上线前还需解决

- 多实例运行需要 PostgreSQL 的版本化迁移和外部任务队列；当前数据库自动迁移只支持加列。
- 登录已有按用户名和直连客户端地址的持久化失败次数限制；注册在生产环境默认关闭。仍缺少网关级限流、账号找回/禁用机制；反向代理部署时需验证真实客户端地址传递并配置 HTTPS。
- 扩充实战案例及评测集，当前只有 2 个场景、5 条检索基准，不能据此宣称广泛覆盖或模型评分准确。
- GitHub Actions 工作流已写入仓库，但未推送验证；部署状态文档中的旧 EC2 信息属于历史快照。
